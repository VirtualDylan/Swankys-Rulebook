# 5 Whys Analysis (/5whys)

**Purpose:** Drill down to the root cause using the 5 Whys technique.

**Prompt:**
1. **Define Issue Name:** Ask for unique issue name.
2. **Problem Statement:** Restate issue clearly.
3. **5 Whys Analysis:** Ask "Why did this happen?" repeatedly (up to 5 times), drilling deeper each step.
4. **Component References:** Identify exact components, files, and line numbers for each cause.
5. **Documentation:** Save analysis in `./docs/troubleshooting/{issueName}/{issueName}-5whys.md`.
6. **Instructions:** Do **not modify code**; focus on reasoning and documentation only.
